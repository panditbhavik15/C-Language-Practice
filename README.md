## ▶️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/panditbhavik15/C-Language-Practice.git
```

### 2. Open the repository

```bash
cd C-Language-Practice
```

### 3. Compile a program

For example:

```bash
gcc "Program 1.c" -o program1
```

### 4. Run the program

**Windows:**

```bash
program1
```

**Linux / macOS:**

```bash
./program1
```
